# NeonCal

**Colorify your life tasks: a neon-styled calendar that color-codes your plans automatically.**

🔗 **Live site:** [neon-cal.vercel.app](https://neon-cal.vercel.app)

---

## The Problem

Bills, birthdays, appointments and subscriptions all end up in one undifferentiated list, so it's hard to see at a glance what kind of month you're heading into.

## The Solution

NeonCal is a monthly calendar where you type a task in plain words and it picks a color category for you.

- **Smart color-coding:** keyword matching sorts each task into a category, for example "rent" or "pay" becomes a bill, "dentist" becomes a doctor visit, "Netflix" becomes a subscription, and "gym" or "yoga" becomes self-care
- **Recurring tasks:** one-time, weekly, bi-weekly or monthly
- **Tap to recolor:** change any task's color if the guess is wrong
- **Built-in calculator** for quick budgeting
- **Saved in your browser:** tasks persist with localStorage, so there's no account to create

## Tech Stack

HTML, CSS, JavaScript, localStorage, deployed on Vercel

## Run It Locally

```bash
git clone https://github.com/lawrencecarrillo/NeonCal.git
cd NeonCal
open index.html
```

No build step or dependencies needed.
